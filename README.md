## The label

> WARNING: This unit may freeze without notice upon remembering something embarrassing from 2011. No patch is available. This is a permanent feature.

A single-line safety warning label for every human being, written in the flat
rhythm of a real printed label. Everyone knows this unit: it stops mid-sentence,
mid-step, mid-shower, because a memory from 2011 just resurfaced — and there is
no fix coming, because the freeze is not a defect. It is a permanent feature.

## How to run

Run `node main.ts` from the repository root. The program creates `/output` if
needed and writes the label exactly, with no trailing newline, to
`/output/entry.txt`.
